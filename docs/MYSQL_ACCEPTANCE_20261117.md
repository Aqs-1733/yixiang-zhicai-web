# MySQL 切换验收 · 2026-11-17

## 已完成

- 网站运行数据库统一为MySQL，移除后端运行路径中的SQLite连接和SQL分支。业务记录与AI调用日志共用连接层。
- 旧库34张表、62条记录迁移成功：逐表核对全部原列、行数及规范化行摘要，用户ID、密码散列、授权、消息及自增高水位保留。新MySQL完整结构35张表，包含旧库尚未使用的资金规划历史表。
- 原SQLite、切换前私有配置与源码保留在仓库外；未覆盖其他项目原有3306 MySQL服务。网站独立实例位于D盘，连接127.0.0.1:3307。
- 金额用DECIMAL保存，日期按ISO字符串返回；记账新增/修改返回实际存入数据库的金额，避免原始浮点尾差。家庭语音消息使用MySQL的LAST_INSERT_ID。
- 画像及家人备注改用更新式upsert，不使用会删除重建行的REPLACE；同批账单导入使用行锁保持幂等。
- 启动脚本增加MySQL连接检查，本机明确配置的独立实例可自动启动。数据库关闭时健康检查返回503，恢复后返回200，不生成空SQLite库。
- 262个前端/小程序文件字节保持不变，157条后端路由声明完整保留。本轮没有进行PPT视觉统一改版。

写入测试全部在专用QA库完成，不污染私人运行数据。真实API测试仅做低成本烟雾验证，不代表语音口音/噪声、所有图片场景或模型建议准确率已全面验收。
