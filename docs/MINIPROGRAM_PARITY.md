# 小程序功能对齐记录 · 2026-11-11

## 原版依据

对照用户提供的两个 ZIP，以 3.0 包中 `颐享智财2.0/miniprogram` 的较完整版本为主，核对 30 个页面、5 个组件。可运行包与该版本的页面主体一致，但缺少理财页“朗读”按钮；本轮已恢复。保留先前的家庭入口、Web 登录和理财小数显示修复。

## 本轮变更

- 原页面样式按路由隔离（37 个样式模块），避免各页 `.panel-mask`、`.add-panel` 等同名选择器相互覆盖。
- 修正 Web 样式对弹窗显示状态的错误假定：原版使用 `panel-show`，不是 `show`；账本弹窗通过条件渲染显示。
- 七天内免登录改为 68×44 像素可操作的标准滑动开关，支持键盘、焦点、禁用状态和原版 change 数据。清除残留伪元素，避免双圆点。
- 修正 `disabled="false"`、连续插值（如金额正负号与数值）、原版内联 rpx 单位、时间选择器、单选分组与默认选中状态。
- 接通头像文件选择与上传、昵称 blur 保存、动态事件表达式、视频事件及 PointerEvent→touch 事件。重绘时保留媒体与表单状态，避免错误触发 blur 或重置视频。
- 浏览器前进/后退与小程序返回同步地址并保留页面实例；同一路由重建时不复用旧页面处理函数。子女进入共享页面时保留子女导航。
- 修复家庭群聊固定输入栏被桌面侧栏遮挡；修复术语弹窗拖动与释放。
- 地图改为真实腾讯底图，支持拖动、缩放、标记点击、地址搜索和选点确认/取消。地图密钥只在后端使用，图片请求鉴权并缓存。
- 吃药提醒导出有效的 ICS：Unix 秒时间转换、UTC 时间、每日重复和提醒字段。
- 删除额外添加的页脚说明、英文装饰、页面介绍、顶部服务说明、侧栏介绍和登录页介绍；保留原版业务标签、输入提示与产品风险信息。

## 验收边界

30 个路由 × 3 个视口的页面检查，以及新增交互测试，均在隔离数据库和合成账号中执行。API 及 AI 原有离线回归、模板/脚本一致性检查另见本地验证记录。静态声明审计覆盖 523 处事件绑定，未发现缺失处理函数或未支持的事件类型；这不等于穷尽每种业务数据组合。

地图图片另做了一次真实腾讯服务调用，HTTP 200、image/png。交互测试中的隔离服务不加载正式 API 密钥，不能据此宣称完成所有第三方服务验收。原有豆包文字/图片/语音接入未变更。

仍需外部材料的项目：

1. 两个原包及工作目录均未提供课程 MP4，课程媒体接口的缺失测试仍为 404；已修复播放器事件适配，但没有把缺少的视频算作通过。
2. 微信免密登录与跳转微信原生能力仍依赖相应平台环境/网站 OAuth 配置；本轮验证了手机号密码登录、七天记住登录与退出，不把它们冒充微信 OAuth 验收。

## 开发复验

设置 `YX_EVIDENCE_DIR` 为含隔离测试账号文件的证据目录，并启动 `127.0.0.1:8001` 隔离服务后，运行：

```powershell
python tests/local_acceptance/audit_miniprogram_parity.py
python tests/local_acceptance/test_mini_parity.py
python tests/local_acceptance/test_mini_components.py
python tests/local_acceptance/browser_acceptance.py
python tests/local_acceptance/test_map_adapter.py
```

实现地图代理时参考[腾讯静态图官方文档](https://lbs.qq.com/service/staticV2/staticGuide/staticDoc)。本地备份、差异与已实测回退脚本不包含真实凭据或用户数据库。
