# 网站功能与测试情况

日期：2026-11-12。这里把已跑通、已修复和未完成的事分开写。测试通过表示这组输入通过，不代表所有设备、图片、方言和外部服务都永远正常。

## 这次改了什么

- 原项目里的小享头像直接复用：黄色帽衫、绿芽、圆脸。网站不再引用机器人图片。新文件与原头像字节一致。
- 配色按提供的界面调整为奶油白、浅黄、墨绿。老人插画分成记账、聊天、散步、找路四个场景，按页面留出图片位置，不再用绝对定位把图压在字上。
- 群聊、家庭留言原来还保留360px的小程序画布，宽屏右边大片留白。这次改为随内容区伸缩；聊天记录单独滚动，输入栏保持可操作。
- 修复附近服务分类在窄屏超大字下横向溢出；语音录入入口改在页面操作区，避免盖住删除等按钮。
- 修复手机记账弹窗：表单独立滚动，标题和确认/取消按钮不再与金额输入框重叠。标准字和超大字均实际关闭弹窗通过。
- 字号按钮保留三档：标准字、大字、超大字。登录/注册页也能调整。修复部分页面字体状态未同步、刷新后显示与保存状态不一致的问题。
- 删掉不必要的宣传标语和拟人套话；操作说明保留关键条件，不把所有文案缩成几个字。AI回答不再硬性限制3—5句，按问题保留步骤。补上北京时间，减少把未经核实的季节、天气说成当前事实。

## 当前仍有的问题和没完成的部分

1. **风险提醒存在可复现的误报，尚未修复。** 输入“图片上没有二维码、链接或按钮。”，当前关键词规则仍会因“二维码”标成high。图像识别链路跑通，不代表风险结论已全面正确；否定句和模型解释中的风险词还需要单独校准。17/17是链路结果，不是建议准确率。
2. **未接入银行授权的实时在售产品目录和正式产品登记核验。** 当前是知识参考和记录，登记查询显示未接入；本地样例不是官方核验结果。
3. **实际支付、转账和资金交易未接入。** 账本记录、资产测算不会替用户移动资金。
4. **外部完整课程内容未补齐。** 目前本地短课可播放；如果要原机构完整课程，还需要稳定且可使用的内容来源。
5. **备用接口仍有历史异常，未在这轮复测。** vivo/BlueLM上轮HTTP404；聚合资讯返回10001，聚合金融返回10020。当前主路径用Ark和官方资讯，不靠这三项冒充成功。初轮Ark的ClosedEndpoint错误已经换接Seed 2.1 Lite并真实调用通过，不再列作当前未接通。
6. **手机实机和生产运行未完整验收。** 尚未完成真实iPhone/Android、Safari、实体麦克风/方言、软键盘弹出、弱网、长时间多人并发，以及生产安全评估。手机尺寸模拟通过不等于所有手机实机通过。
7. **后台/离线消息推送未做。** 现在是前台会话约1.5秒自动同步，切到后台不承诺即时推送。
8. **公网域名、HTTPS和服务器托管未部署。** 当前是本地8004；网站微信登录按此前要求不做。

测试文案时还发现模型在11月误说“现在夏天”。已补当前北京时间和未核实天气限制，复测回答改为先看天气、按体力安排；这只能说明该样本已纠正，不保证模型以后所有内容都正确。

## API配置与GitHub怎么分开

当前Ark、百度语音、腾讯位置服务的私有配置已经在本机，不需要重新发到聊天。

| 可以放仓库 | 留在本机私有配置/运行目录 |
|---|---|
| API调用代码、变量名、不含密钥的接口地址、模型ID、空白.env.example | ARK_API_KEY；BAIDU_API_KEY/BAIDU_SECRET_KEY；TENCENT_MAP_KEY；JWT_SECRET |
| 前后端源码、测试脚本、项目插画和有来源的课程素材 | BLUELM_API_KEY、VIVO相关授权密钥、JUHE_BULLETIN_KEY/JUHE_FINANCE_KEY等备用服务凭证 |
| 配置说明和去掉个人数据的文档 | 真实.env、业务数据库、上传录音/照片、账号Token、商户证书/私钥、个人截图 |

本机.env和运行数据库/上传目录受.gitignore排除；发布前另扫描已知私有值和Git历史。Fork代码的人需要配置自己的服务密钥，不会从仓库拿到你的密钥。若要继续启用备用接口，只需在本机.env核对对应产品的URL、模型/鉴权和密钥。
