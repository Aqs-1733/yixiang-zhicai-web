# 2026-11-12 可靠性修复与验收

## 本轮问题及改动

1. **课堂反复刷新/发白**：setData曾每秒替换整张课程卡，反复启动透明度动画。现在按原节点键增量更新DOM，保持播放器、卡片、输入框和滚动容器连接；选集和进度按账号保存，返回页面不重置。
2. **播放源不稳定**：主课堂全部10门本地MP4，本地海报、音轨、授权与参考来源随项目提供。原8门外部HLS仅保留来源链接，不当作主播放依赖。新增8门为同主题原创中文短课，不冒称原机构完整视频。
3. **新闻列表空白/详情依赖首页缓存**：增加独立列表和按已核验ID从服务器读取详情；持久保存公开资讯元数据和有限正文节选。正文获取失败会显示真实状态和官方原文入口，不制造文章正文或最新日期。另修复系统启动不足十分钟时首次抓取被缓存时钟误跳过的问题，并增加低uptime回归。
4. **家庭协同需手动刷新**：前台约1.5秒轮询会话、约4秒更新未读数；消息更新不清空输入草稿。仅取最近100条私信/200条群聊并保持时间顺序。撤销权限立即清除显示，恢复后重新读取。
5. **家庭语音到达却播不了**：GET补回可播放voice_url及duration；旧URL格式兼容，新消息保存语音元数据。录音回调按当前页面隔离，切换页面取消旧录音，避免错发到另一会话。
6. **刷新意外登出**：未勾选七天免登录使用标签页sessionStorage，刷新保留登录；新会话不继承该认证。勾选后的七天期限、过期退出、主动退出仍生效。
7. **账单重复入账**：同批导入事务内校验归属与状态，确认按钮防重复提交；保留解析日期、金额及收支方向。
8. **页面拥挤/空白与挡住按钮**：个人画像改成全宽身份卡、分组风险摘要；增加本地老人插画模块头；小屏首页改为纵向、附近地图回归正常文档流，缩放控件移至左侧避开语音浮钮。

## 复现与事实范围

浏览器为Windows本机Edge/Chromium。屏宽1440、960、390，字体normal/large/xlarge。原生播放器实际解码，不用人工派发play/ended事件替代播放。家庭测试开启两个独立浏览器上下文，实际发送、接收和播放。识别测试使用内容已知的合成收据和产品截图，并调用真实Ark；语音录音为可重复的本机合成音频，GPS为已知坐标注入后调用真实腾讯转换/路线。

上述结果不代表任意设备实体麦克风、所有方言/任意照片识别准确率或第三方服务永久可用。前台同步不是离线推送。官方新闻不是全网聚合，有限节选不是完整原文。产品为知识参考，未接入银行授权实时在售目录、实际支付交易；网站微信登录不做。

本机运行配置保留在被Git忽略的backend/.env；测试记录写入独立副本，不向用户账本/家庭账号写入测试记录。公开前扫描暂存区与完整Git历史中的私有配置值、令牌、私钥及数据库文件。
