# 颐享智财 · 全页面精修设计版 Web

## 本次修改

本轮针对上一版深绿科技风进行前端改版。取消深绿主色、星球图形和英文装饰小字，采用奶油白、蜜桃橙、暖黄、淡粉、淡紫的卡通适老风格。加入爷爷奶奶、小享机器人的卡通图片，重新设计登录左侧插画区、首页横幅、导航、按钮、卡片、聊天面板和子女端卡片。

移动端、平板、桌面端使用同一套页面源码和响应式布局；网页背景不再直接套用微信小程序竖屏背景。正文、导航、表单和按钮的文字已整体放大。保留页面中的功能按钮和必要的安全提示，取消不必要的英文微型标签与装饰文字。

本轮只增加 `site/cute.css` 和 `site/cute.js`、`site/assets/cute/` 插画资源，并更新 `site/index.html` 引入文件。原始业务页面 `miniprogram/pages/`、组件 `miniprogram/components/`、FastAPI `backend/` 和小程序 Web 兼容层 `site/compat.js` 未删除，也没有通过重写简化业务流程替代原有代码。

## 运行方法（Windows）

1. 解压整个文件夹到 D 盘，例如 `D:\颐享智财_Web_精修设计版_20261110`。
2. 在本项目文件夹的**上一级**放置您之前上传的原始 `颐享智财_可运行产品包.zip`。如果需要继续复用旧 API 配置，不要把里面 `.env` 的密钥手动写入网页前端。
3. 双击 `启动网站.bat`。首次使用会建立 Python 虚拟环境并安装依赖；找不到 `.env` 时，启动脚本会尝试通过原始 ZIP 导入 API 配置。
4. 浏览器打开 `http://127.0.0.1:8000/site/`。FastAPI 接口文档在 `/docs`。
5. 您也可以先双击 `网页预览.html`，查看**实际页面渲染截图**在电脑、平板、手机上的效果。该截图预览不执行登录或金融功能。

原项目演示账号（仅本地测试环境）：长辈 `13800000000 / 123456`，子女 `13900000000 / 123456`。正式部署前必须更换演示密码，并检查认证、授权和敏感数据处理。

## 功能保留和测试边界

- 30 个原始页面和 5 个原始自定义组件均保留。
- 现有文字、图片、语音输入、产品识别、新闻、老人／子女登录、账本、家庭协同、健康与提醒等业务代码仍在工程内，调用逻辑不因本次视觉升级被删掉。
- `验证工程.py` 的 23 项工程级检查通过；原始 30 个页面进行了浏览器模拟响应下的加载烟雾测试，其中 29 个如预期停留在目标路由，家庭页出现自动跳转，需要登录态复测。
- 登录、图片、语音、大模型、新闻实时数据等**没有**完成本轮全部真实后端端到端复测。浏览器截图渲染在独立静态资源代理中完成；与实际网络联调结果必须分开看。
- 新闻和视频在无真实联网环境可能显示“暂无资讯”或播放失败，这反映预览环境未接入真实数据，不代表原业务已删除。
- 密钥文件 `.env` 没有放在公开交付包中。需要使用原始 ZIP 提供的密钥，继续按照 API 报告进行有效性测试。

## 视觉与交互原则

使用暖色块区分功能，保留操作较大的点击区域。重要标题建议 22–36 px，常规文本约 16–19 px，按钮最小高度通常 44–49 px。进入动画、悬停效果和卡片浮起效果会遵守系统“减少动态效果”设置。

设计用途是养老金融信息辅助、教育、记录及风险提示；不提供真实转账、买卖和赎回操作。
